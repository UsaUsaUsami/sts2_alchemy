# 錬金術師MOD（Alchemist）— Slay the Spire 2向け試作版

素材採取・カード錬成・ポーション調合を軸とする錬金術師キャラクターのMOD。現状は試作段階。詳細な仕様方針は`AGENTS.md`、実装済みの変更は`docs/design-decisions.md`を参照。

## 対応バージョン

- Slay the Spire 2: v0.111.0
- BaseLib-StS2: v3.4.5（[Alchyr/BaseLib-StS2](https://github.com/Alchyr/BaseLib-StS2)）

異なるゲーム版・BaseLib版での動作は未確認。`scripts/install.ps1`がバージョン不一致を検出すると導入を停止する。

## ビルド

前提：`.tools/dotnet`にSDKが配置済み（`scripts/env.ps1`が参照）。未配置の場合は`scripts/env.ps1`の参照先を確認し、.NET SDK 9.0.318相当を用意する。

```powershell
.\scripts\build.ps1
# GameRoot既定値は "C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2"
# 別の場所にインストールしている場合は: .\scripts\build.ps1 -GameRoot "D:\Games\...\Slay the Spire 2"
```

内部で以下を順に行う：
1. `tests/Alchemist.Core.Tests`のルール検証テストを実行（失敗時はビルドを中断）
2. `src/Alchemist`をReleaseビルド
3. `dist/Alchemist/`に`Alchemist.dll`・`Alchemist.json`を配置

## 導入

```powershell
.\scripts\install.ps1
```

- StS2が起動中の場合はエラーで停止する。事前に終了しておくこと。
- ゲーム本体のバージョン、`mods/BaseLib/BaseLib.json`のバージョンが対応版と異なる場合はエラーで停止する。
- `mods/Alchemist`が既に存在する場合は停止する。更新にはゲームを終了して `scripts/update.ps1` を実行する。旧DLL・マニフェストを `artifacts/backups/` に保存してから更新する。
- 導入後、ゲーム内のMOD設定でBaseLibとAlchemistを有効化する必要がある（初回導入時はMOD一覧に追加されるだけで、既定では無効の場合がある）。

## v0.16.0：相転移の集約と素材経済の見直し

- 相転移の判定と効果を1か所（`PhaseTransitions`）にまとめた。効果は移った先の相だけで決まる：地＝2ブロック、水＝脱力1、火＝3ダメージ、風＝1ドロー。
- 工房で作る錬成カードにも相が付き、相転移に参加するようになった。相は素材構成から決まり、カードの説明とプレビューに表示される。
- 「相を進める」錬成カードでも、通常の相転移効果が発動するようになった。
- 《炉の起動》は、無相のとき・2回使い切ったとき・廃棄できる手札がないときは使用できない（空撃ちで回数を失わない）。
- 工房の改造は、休憩所で強化済みのカードにも行えるようになった。
- 素材の獲得量を1回1個、素材ボックスの容量を10個へ戻した。旧版で11個以上持っているセーブも読み込め、10個を下回るまで新しい素材は受け取り待ちになる。
- パワー《相の共鳴》（相転移するたびブロック）を追加した。v0.15.0で商人に入ると失敗していた不具合（カードプールにパワーがなかった）もこれで直した。
- 相転移のたびに素材ボックスが光り、「○相へ転移」の吹き出しが出る。左上の素材ボタンは現在相の色で表示される。

## v0.15.0：四元素の相転移と4設備の工房

- 通常戦闘後のカード報酬を復活し、錬金術師専用の小規模カードプール（地・水・火・風各2枚＋《即席錬成》）から選べるようにした。
- 戦闘開始時は無相。属性カードを使うとその相になり、異なる相へ移った時だけ、移動先に応じて地＝ブロック、水＝脱力、火＝ダメージ、風＝ドローが発動する。相はターンをまたぎ、戦闘終了でリセットされる。
- 初期レリックが各戦闘の最初に《炉の起動》を2枚手札へ加える。現在相に応じて鉄・薬草・火薬・エーテルを採取するため、《携帯錬金炉》を引く必要はない。
- 《即席錬成》は所持する通常素材を1個消費し、対応する0コスト・廃棄の元素カードを手札へ作る。
- 工房は「錬成・改造・調薬・付与」の4設備に分かれ、各設備を1訪問につき1回ずつ使える。改造は通常アップグレードとは別の恒久エンチャントとして保存される。
- 調薬では通常素材1個から、地相・水相・火相・風相の小瓶を1本作る。ポーション枠が満杯なら素材も設備回数も消費しない。

旧v0.13.0以前の節は開発履歴として残している。そこにある「カード報酬なし」「ターンごとの素材相」「工房での連続錬成」は現在の仕様ではない。

## v0.13.0：錬成バランスの基盤修正

- 作成可能なレシピを83枚から65枚へ整理。2素材は順不同の10組み合わせにつき1枚、3素材20枚、4素材35枚とした。
- 旧2素材レシピ18枚の定義IDは既存セーブの読込用に残すが、新しく作ることはできない。
- 2素材帯から恒久筋力・恒久敏捷・多段攻撃を外した。多段攻撃は3素材と4素材に各1枚だけ配置した。
- 3素材の筋力・敏捷は最大1、4素材は最大2へ抑えた。3枚のレシピに、現在ターンを変えず素材相だけを進める効果を追加した。
- 既存カード強化は工房1か所につき1枚。カード錬成は素材が続く限り複数回行える。
- 商人の通常画面に「錬金素材を見る」ボタンを追加。訪問ごとに決定する通常素材3枠を、各1回・35Gで購入できる。再表示やロードで在庫は変わらない。
- 素材取得2倍、容量20、通常カード報酬なしという経済の基本条件は維持している。

## v0.9.1：カードと素材の双方向錬成UI

工房のカード錬成を、次の2方向から利用できるようにした。

- **カードから探す**：従来どおり完成カードの一覧から選び、必要素材を確認する。
- **素材から作る**：Minecraftの作業台のように通常素材を2枠へ置き、その組み合わせから作れるカードだけを表示する。同種素材も2個置ける。素材の順番は問わない。

素材スロットへの配置はプレビューであり、この時点では消費しない。表示されたカードを選んで「このカードを作る」を確定した時だけ素材を2個消費する。

## v0.9.0：希少素材・恒久加工・レシピ表示修正

希少素材3種を追加した。工房の「希少加工」で錬成カード1枚へ1つだけ恒久効果を刻む。素材は加工時に消費され、取り外し・回収・上書きはできない。

| 希少素材 | 恒久効果 |
|---|---|
| 水銀 | 保留を得る |
| 星砂 | リプレイ1回を得て、カード効果が合計2回発動する |
| 虚無結晶 | コストが1減り、廃棄を得る |

- ボスの2枠中1枠は3候補すべて希少素材。初期3種をすべて提示する。
- エリート枠とボスの非保証枠は、25%の確率で3候補中1個が希少素材になる。
- 通常素材と希少素材は容量10を共有し、満杯なら同じ交換・辞退手順を使う。
- schema 1/2の既存ランは、通常素材と未解決報酬を保持したままschema 3へ移行する。
- レシピ一覧を初めて開いた時、一部カードに `If you can read this, there is a bug.` が残る問題を修正した。プールされたカード表示ノードを、内部ラベルの準備後に再描画する。

## v0.8.0：炉の起動による素材採取

通常素材は、敵を倒した時ではなく、**《炉の起動》で手札を廃棄した直後**に現在相の素材を1個得る。炉の起動は戦闘全体で2回までなので、敵が1体でも複数でも、1戦で狙える通常素材は同じ最大2個になる。カードを選ばず取り消した場合や、廃棄に失敗した場合は素材を得ない。

## v0.7.0：エリート・ボスの素材報酬

《炉の起動》による通常素材の採取とは別に、報酬画面へ素材を選ぶ枠を追加した。

| 部屋 | 枠 | 内容 |
|---|---|---|
| エリート | 1枠 | 3候補から素材1個 |
| ボス | 2枠 | 各3候補から素材1個（計2個） |

- ゴールド・カード・レリック・ポーションの既存報酬はそのまま残る。素材枠が追加されるだけで、置き換えはしない。
- 候補はランのシードと報酬枠IDだけから決まる。画面を開き直しても、セーブして再開しても、同じ3候補が出る。ゲーム側の乱数列は消費しない。
- 素材ボックスが満杯のときは、通常素材と共通の受け取り手順（交換か辞退）へ合流する。黙って捨てることはない。
- 枠の辞退は可能。辞退した枠は戻らない。
- 未解決の枠が残っているあいだは次の部屋へ進めず、工房での錬成・強化もできない。
- v0.7.0時点では希少素材が未実装だった。v0.9.0でボスの片方を希少確定枠へ変更した。

## v0.4.0：マップ工房・既存カード強化・連続する素材相

この節はv0.4.0当時の記録。v0.13.0以降、通常素材2個で作れるカードは10種で、各組み合わせにつき1枚となっている。

| 目指すデッキ | 主役のレシピ・未強化時の効果 |
|---|---|
| 大きな一撃 | 鉄＋鉄《錬鉄の大剣》：2コスト、28ダメージ＋8ブロック、保留 |
| 毒で押し切る | 薬草＋薬草《猛毒培養槽》：1コストのパワー、毎ターン敵全体に毒4 |
| 廃棄を戦力に | 鉄＋エーテル《循環錬成炉》：2コストのパワー、廃棄のたび5ブロック＋1ドロー |
| 集団戦の切り札 | 火薬＋エーテル《エーテル爆縮》：1コスト、全体24ダメージ＋2ドロー、廃棄 |

このほか徹甲榴弾・毒霧爆弾・濃縮毒液を追加し、既存5種も強化。数値は強めの試作値で、通しプレイによるバランス検証はこれから。既存カードのIDとラン保存形式は維持するが、新カードを含むセーブを旧MODへ戻すことは非対応。

v0.3.0では《合金乱舞》《回転式錬金砲》《毒針斉射》《連鎖爆轟》《星屑弾幕》などの多段攻撃、《金剛の霊薬》《火薬律動》などの筋力、《補強行列》《軽業の蒸留液》などの敏捷、《戦支度の霊薬》《霊質変成》など攻守両方を伸ばすパワーを追加した。多段攻撃は筋力が各ヒットへ適用される。

工房は左側に素材ボックス、右側に完成後のカードそのものを一覧表示する。カードを選ぶと一枚を大きく表示し、必要素材、役割、使い方、現在効果、強化後効果を確認してから「このカードを作る」か「一覧へ戻る」かを選べる。作成可能な候補だけへの絞り込みにも対応する。

工房はマップ生成時に既存の「？」を置き換えて配置される。通常の休憩所と同程度の個数で、序盤から中盤にも到達できるようAct内へ分散し、金色の商店型アイコンと「工房」ラベルで事前表示する。通常の休憩所、商人、戦闘、エリートは置き換えない。

工房ではカード錬成と既存カード強化を切り替えられる。強化コストは試作として、アタック＝鉄＋火薬、スキル＝薬草＋エーテル、パワー＝火薬＋エーテル。現在と強化後のカードを並べて確認してから実行する。

素材相は戦闘ごとに鉄へ戻らない。戦闘終了時の次の相を保存し、次の戦闘はそこから開始する。たとえば鉄相で終えた次の戦闘は薬草相から始まる。

## 既知の制限

- 作成可能なレシピは65種。3・4素材帯にはまだ似た効果の組み合わせが多く、通しプレイを基にした個別調整は継続中。
- 希少加工の取り外し・回収・上書きと、通常カードへの加工は未実装。
- 素材報酬のアイコンは既存レリック画像の流用。専用アイコンは未作成。
- マルチプレイ・他キャラクターとの共存は未検証。

## アンインストール時の注意

`mods/Alchemist`フォルダを削除するだけでよいが、Alchemist使用中のランのセーブは復元できなくなる可能性がある。アンインストール前に該当ランを終了しておくことを推奨する。
