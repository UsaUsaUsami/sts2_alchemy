# 錬金術師MOD（Alchemist）— Slay the Spire 2向け試作版

素材採取・カード錬成・ポーション調合を軸とする錬金術師キャラクターのMOD。現状は試作段階。詳細な仕様方針は`AGENTS.md`、実装済みの変更は`docs/design-decisions.md`を参照。

## 対応バージョン

- Slay the Spire 2: v0.111.0
- BaseLib-StS2: v3.4.5（[Alchyr/BaseLib-StS2](https://github.com/Alchyr/BaseLib-StS2)）

異なるゲーム版・BaseLib版での動作は未確認。`scripts/install.ps1`がバージョン不一致を検出すると導入を停止する。

## ビルド

前提：`.tools/dotnet`にSDKが配置済み（`scripts/env.ps1`が参照）。未配置の場合は`scripts/env.ps1`の参照先を確認し、.NET SDK 9.0.318相当を用意する。

```powershell
.\scripts\build.ps1
# GameRoot既定値は "C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2"
# 別の場所にインストールしている場合は: .\scripts\build.ps1 -GameRoot "D:\Games\...\Slay the Spire 2"
```

内部で以下を順に行う：
1. `tests/Alchemist.Core.Tests`のルール検証テストを実行（失敗時はビルドを中断）
2. `src/Alchemist`をReleaseビルド
3. `dist/Alchemist/`に`Alchemist.dll`・`Alchemist.json`を配置

## 導入

```powershell
.\scripts\install.ps1
```

- StS2が起動中の場合はエラーで停止する。事前に終了しておくこと。
- ゲーム本体のバージョン、`mods/BaseLib/BaseLib.json`のバージョンが対応版と異なる場合はエラーで停止する。
- `mods/Alchemist`が既に存在する場合は停止する。更新にはゲームを終了して `scripts/update.ps1` を実行する。旧DLL・マニフェストを `artifacts/backups/` に保存してから更新する。
- 導入後、ゲーム内のMOD設定でBaseLibとAlchemistを有効化する必要がある（初回導入時はMOD一覧に追加されるだけで、既定では無効の場合がある）。

## v0.21.0：報酬60枚・錬成20種・素材の獲得量を2個に

- カード報酬のプールを60枚に絞った（相転移17・生命17・汎用26）。外した25枚は報酬・商人に出なくなるだけで、旧セーブのデッキにあれば使える。
- 工房の錬成を20種にした。3〜5個の素材で作る固有レシピを10種追加（鋼の砦、爆裂フラスコ、精霊の触媒、賢者の血、培養槽、血肉の鎧、融合、分裂、真理の扉、三相の奔流）。工房の素材スロットは最大5個。
- 《炉の起動》の素材獲得量を1回2個、素材ボックスの容量を20に戻した（v0.16.0で誤って1個・10にしていた）。エリート・ボスの素材選択は1個のまま。

## v0.20.0：ホムンクルスが場に立つように、生命軸カード10枚、素材消費カード

- **ホムンクルス**がネクロバインダーのオスティのように場に立つようになった。ホムンクルスHPがそのままHPで、錬金術師への攻撃のうちブロックを超えた分を代わりに受ける（毒・HP喪失は受けない）。0になると倒れ、HPを得ると復活する。見た目は当面オスティのものを借りている。
- 生命軸のカード10枚を報酬プールに入れた：吸血の刃、瘴気の針、肉の壁、命の弾丸、養分、共生、命脈の一撃、腐食の抱擁、生命の奔流、目覚めた器（名前・数値は仮）。代わりに毒の雫・水刃・砂塵の構え・火炎斬り・瘴気・毒液散布・焼却・濃縮・水神の加護・順風を報酬・商人に出さないようにした（旧セーブのデッキにあれば、そのまま使える）。報酬プールは85枚。
- 素材消費カードを「消費する素材をカードが指定する」形にした：素材爆弾（火薬）、触媒反応（エーテル）。新カード鉄壁錬成（鉄）、薬毒の滴（薬草）を追加。素材がなくても使えるカードは、素材があると代わりに大きな効果になる。素材投入は今までどおり好きな素材を選ぶ。

## v0.19.0：生命軸の手本カードと無限ループ対策

`docs/design-axes.md`（2026-09-26の設計方針）のマイルストーン1の一部。

- 生命軸の仕組みを追加した。
  - **ドレイン**：敵のデバフ。毒と同じく敵のターン開始時に、数値分のHPを失わせて1減る。奪ったHPはホムンクルスHPになる。
  - **ホムンクルス**：生命を溜める器。最初にホムンクルスHPを得るとプレイヤーにアイコンが付き、数値が表示される。戦闘ごとにリセット。
  - **死亡**：次の自分のターン開始時に死亡するデバフ。瓶詰めの妖精などで防げる。
- 手本カード7枚を報酬プールに追加した：生命の供物、吸精の瘴気、大いなる業、人体錬成、生命の収穫、デバフ転写、還元（一部の名前は仮）。報酬プールは83枚。
- 相転移でドロー枚数が増えないようにした（風への転移は常に1ドロー。強化の対象外）。これに合わせて天空・風の刃・勢い・相乗の効果を変え、改造の対象から風のカードを外した。
- 心核を相ごとに作り直した：流水の心核は脱力に加えて弱体、疾風の心核は次の相転移を強化。
- ジ・アーキテクト（最終イベント）で「進む」が出ず止まる不具合を直した。
- 素材の獲得量（1回2個）・容量（20）への復元は、素材消費カードの見直しと同時に行うため、この版ではまだ1個・10のまま。

## v0.18.0：ポーションが使えない不具合などの修正

- 工房で作ったポーションを使おうとすると使えなかった不具合を直した。
- 「廃棄」「保留」がカード本文に二重に表示されていたのを直した。
- 旧錬成カード（65種と旧基本レシピ）と《携帯錬金炉》を削除した。**これらを含む旧版のランは続きから再開できない。** 新しいランを始めること。
- レア《連鎖反応》（このターンの相転移1回につき10ダメージ）を追加した。報酬プールは76枚。

**更新方法**：ゲームを終了し、`.\scripts\build.ps1`のあと`.\scripts\update.ps1`を実行する。起動ログ（`%APPDATA%\SlayTheSpire2\logs\godot.log`）の`[Alchemist] Initialized`の行で導入版を確認できる。

## v0.17.0：カード報酬プール75枚と錬成10種

- カード報酬と商人に並ぶ錬金術師カードを75枚にした（地・水・火・風各16枚、無相11枚）。他キャラクターと同じく、Commonにパワーはない。
- 工房の錬成を、通常素材2個から作る10種へ作り直した。
  - 同じ素材2個：その相への相転移を強化する「心核」パワー（大地・流水・劫火・疾風）。
  - 違う素材2個：効果の後に2つの相へ続けて入る複相カード（泥の城壁、溶岩弾、砂嵐、蒸気爆発、毒霧雨、火炎旋風）。1枚で相転移が最大2回起きる。
- 以前の錬成カード（65種）は新しく作れない。すでにデッキにあるカードはそのまま使える。
- 希少素材の付与は、新旧どちらの錬成カードにも行える。
- カードが二重に登録され、報酬の抽選で各カードが2回分数えられていた不具合を直した。

## v0.16.0：相転移の集約と素材経済の見直し

- 相転移の判定と効果を1か所（`PhaseTransitions`）にまとめた。効果は移った先の相だけで決まる：地＝2ブロック、水＝脱力1、火＝3ダメージ、風＝1ドロー。
- 工房で作る錬成カードにも相が付き、相転移に参加するようになった。相は素材構成から決まり、カードの説明とプレビューに表示される。
- 「相を進める」錬成カードでも、通常の相転移効果が発動するようになった。
- 《炉の起動》は、無相のとき・2回使い切ったとき・廃棄できる手札がないときは使用できない（空撃ちで回数を失わない）。
- 工房の改造は、休憩所で強化済みのカードにも行えるようになった。
- 素材の獲得量を1回1個、素材ボックスの容量を10個へ戻した。旧版で11個以上持っているセーブも読み込め、10個を下回るまで新しい素材は受け取り待ちになる。**（訂正：古い指示書を参照した誤りで、意図した変更ではなかった。1回2個・容量20へ戻す予定。`docs/design-axes.md` 0.1）**
- パワー《相の共鳴》（相転移するたびブロック）を追加した。v0.15.0で商人に入ると失敗していた不具合（カードプールにパワーがなかった）もこれで直した。
- 相転移のたびに素材ボックスが光り、「○相へ転移」の吹き出しが出る。左上の素材ボタンは現在相の色で表示される。

## v0.15.0：四元素の相転移と4設備の工房

- 通常戦闘後のカード報酬を復活し、錬金術師専用の小規模カードプール（地・水・火・風各2枚＋《即席錬成》）から選べるようにした。
- 戦闘開始時は無相。属性カードを使うとその相になり、異なる相へ移った時だけ、移動先に応じて地＝ブロック、水＝脱力、火＝ダメージ、風＝ドローが発動する。相はターンをまたぎ、戦闘終了でリセットされる。
- 初期レリックが各戦闘の最初に《炉の起動》を2枚手札へ加える。現在相に応じて鉄・薬草・火薬・エーテルを採取するため、《携帯錬金炉》を引く必要はない。
- 《即席錬成》は所持する通常素材を1個消費し、対応する0コスト・廃棄の元素カードを手札へ作る。
- 工房は「錬成・改造・調薬・付与」の4設備に分かれ、各設備を1訪問につき1回ずつ使える。改造は通常アップグレードとは別の恒久エンチャントとして保存される。
- 調薬では通常素材1個から、地相・水相・火相・風相の小瓶を1本作る。ポーション枠が満杯なら素材も設備回数も消費しない。

v0.13.0以前の節は`docs/history.md`へ移した。そこにある「カード報酬なし」「ターンごとの素材相」「工房での連続錬成」は現在の仕様ではない。

## 既知の制限

- 錬成は2素材の10種のみ。3〜5素材の固有レシピは未実装（`docs/design-axes.md` 7.1）。
- 生命軸（ドレイン・ホムンクルス・死亡）は手本カード7枚のみ。報酬プールの置き換えは未実施。
- 希少加工の取り外し・回収・上書きと、通常カードへの加工は未実装。
- 素材報酬のアイコン、カード絵、パワーアイコンは既存素材の流用。専用アートは未作成。
- マルチプレイ・他キャラクターとの共存は未検証。

## アンインストール時の注意

`mods/Alchemist`フォルダを削除するだけでよいが、Alchemist使用中のランのセーブは復元できなくなる可能性がある。アンインストール前に該当ランを終了しておくことを推奨する。
