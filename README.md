# 錬金術師MOD（Alchemist）— Slay the Spire 2向け試作版

素材採取・カード錬成・ポーション調合を軸とする錬金術師キャラクターのMOD。現状は試作段階（AGENTS.mdのM0〜M1範囲）。詳細な仕様方針は`AGENTS.md`を参照。

## 対応バージョン

- Slay the Spire 2: v0.111.0
- BaseLib-StS2: v3.4.5（[Alchyr/BaseLib-StS2](https://github.com/Alchyr/BaseLib-StS2)）

異なるゲーム版・BaseLib版での動作は未確認。`scripts/install.ps1`がバージョン不一致を検出すると導入を停止する。

## ビルド

前提：`.tools/dotnet`にSDKが配置済み（`scripts/env.ps1`が参照）。未配置の場合は`scripts/env.ps1`の参照先を確認し、.NET SDK 9.0.318相当を用意する。

```powershell
.\scripts\build.ps1
# GameRoot既定値は "C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2"
# 別の場所にインストールしている場合は: .\scripts\build.ps1 -GameRoot "D:\Games\...\Slay the Spire 2"
```

内部で以下を順に行う：
1. `tests/Alchemist.Core.Tests`のルール検証テストを実行（失敗時はビルドを中断）
2. `src/Alchemist`をReleaseビルド
3. `dist/Alchemist/`に`Alchemist.dll`・`Alchemist.json`を配置

## 導入

```powershell
.\scripts\install.ps1
```

- StS2が起動中の場合はエラーで停止する。事前に終了しておくこと。
- ゲーム本体のバージョン、`mods/BaseLib/BaseLib.json`のバージョンが対応版と異なる場合はエラーで停止する。
- `mods/Alchemist`が既に存在する場合は停止する。更新にはゲームを終了して `scripts/update.ps1` を実行する。旧DLL・マニフェストを `artifacts/backups/` に保存してから更新する。
- 導入後、ゲーム内のMOD設定でBaseLibとAlchemistを有効化する必要がある（初回導入時はMOD一覧に追加されるだけで、既定では無効の場合がある）。

## v0.8.0：炉の起動による素材採取

通常素材は、敵を倒した時ではなく、**《炉の起動》で手札を廃棄した直後**に現在相の素材を1個得る。炉の起動は戦闘全体で2回までなので、敵が1体でも複数でも、1戦で狙える通常素材は同じ最大2個になる。カードを選ばず取り消した場合や、廃棄に失敗した場合は素材を得ない。

## v0.7.0：エリート・ボスの素材報酬

《炉の起動》による通常素材の採取とは別に、報酬画面へ素材を選ぶ枠を追加した。

| 部屋 | 枠 | 内容 |
|---|---|---|
| エリート | 1枠 | 3候補から素材1個 |
| ボス | 2枠 | 各3候補から素材1個（計2個） |

- ゴールド・カード・レリック・ポーションの既存報酬はそのまま残る。素材枠が追加されるだけで、置き換えはしない。
- 候補はランのシードと報酬枠IDだけから決まる。画面を開き直しても、セーブして再開しても、同じ3候補が出る。ゲーム側の乱数列は消費しない。
- 素材ボックスが満杯のときは、通常素材と共通の受け取り手順（交換か辞退）へ合流する。黙って捨てることはない。
- 枠の辞退は可能。辞退した枠は戻らない。
- 未解決の枠が残っているあいだは次の部屋へ進めず、工房での錬成・強化もできない。
- 希少素材はまだ存在しないため、ボスの「希少確定枠」（AGENTS.md 4.4）は未実装。現状は2枠とも通常素材の3択で、希少素材の実装時（M3）に対応する。

## v0.4.0：マップ工房・既存カード強化・連続する素材相

通常素材2個で作れるカードは28種。4素材の順不同の全10組み合わせに複数の作成方針があり、工房には役割・使い方・強化後の効果・不足素材を表示する。

| 目指すデッキ | 主役のレシピ・未強化時の効果 |
|---|---|
| 大きな一撃 | 鉄＋鉄《錬鉄の大剣》：2コスト、28ダメージ＋8ブロック、保留 |
| 毒で押し切る | 薬草＋薬草《猛毒培養槽》：1コストのパワー、毎ターン敵全体に毒4 |
| 廃棄を戦力に | 鉄＋エーテル《循環錬成炉》：2コストのパワー、廃棄のたび5ブロック＋1ドロー |
| 集団戦の切り札 | 火薬＋エーテル《エーテル爆縮》：1コスト、全体24ダメージ＋2ドロー、廃棄 |

このほか徹甲榴弾・毒霧爆弾・濃縮毒液を追加し、既存5種も強化。数値は強めの試作値で、通しプレイによるバランス検証はこれから。既存カードのIDとラン保存形式は維持するが、新カードを含むセーブを旧MODへ戻すことは非対応。

v0.3.0では《合金乱舞》《回転式錬金砲》《毒針斉射》《連鎖爆轟》《星屑弾幕》などの多段攻撃、《金剛の霊薬》《火薬律動》などの筋力、《補強行列》《軽業の蒸留液》などの敏捷、《戦支度の霊薬》《霊質変成》など攻守両方を伸ばすパワーを追加した。多段攻撃は筋力が各ヒットへ適用される。

工房は左側に素材ボックス、右側に完成後のカードそのものを一覧表示する。カードを選ぶと一枚を大きく表示し、必要素材、役割、使い方、現在効果、強化後効果を確認してから「このカードを作る」か「一覧へ戻る」かを選べる。作成可能な候補だけへの絞り込みにも対応する。

工房はマップ生成時に既存の「？」を置き換えて配置される。通常の休憩所と同程度の個数で、序盤から中盤にも到達できるようAct内へ分散し、金色の商店型アイコンと「工房」ラベルで事前表示する。通常の休憩所、商人、戦闘、エリートは置き換えない。

工房ではカード錬成と既存カード強化を切り替えられる。強化コストは試作として、アタック＝鉄＋火薬、スキル＝薬草＋エーテル、パワー＝火薬＋エーテル。現在と強化後のカードを並べて確認してから実行する。

素材相は戦闘ごとに鉄へ戻らない。戦闘終了時の次の相を保存し、次の戦闘はそこから開始する。たとえば鉄相で終えた次の戦闘は薬草相から始まる。

## 既知の制限

- レシピは28種。ベース3種を含む30入力のハイブリッド合成と、希少素材の装着/分解は未実装（M3範囲）。
- 希少素材が未実装のため、ボス報酬の希少確定枠はまだない。2枠とも通常素材の3択。
- 素材報酬のアイコンは既存レリック画像の流用。専用アイコンは未作成。
- マルチプレイ・他キャラクターとの共存は未検証。

## アンインストール時の注意

`mods/Alchemist`フォルダを削除するだけでよいが、Alchemist使用中のランのセーブは復元できなくなる可能性がある。アンインストール前に該当ランを終了しておくことを推奨する。
