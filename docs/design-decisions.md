# 設計判断記録

## 2026-09-21: ビルドスクリプトの文字エンコーディング修正

- `scripts/build.ps1`・`scripts/install.ps1`はUTF-8（BOMなし）で保存されていた。Windows PowerShell 5.1はBOMなしUTF-8スクリプトをシステム既定コードページで読み込むため、日本語コメント・文字列を含む行でパースエラーが発生し、スクリプトが実行不能だった。
- 対応：両ファイルにUTF-8 BOMを付与。内容（コマンド・ロジック）は変更していない。
- 影響：スクリプトの実行結果には影響しない。今後このリポジトリに追加する`.ps1`ファイルも同様にBOM付きUTF-8で保存すること。

## 2026-09-21: 実機BaseLibをv3.2.0からv3.4.5へ更新

- 経緯：実機の`mods/BaseLib`がv3.2.0のままで、プロジェクトのビルド参照（`.tools/BaseLib-3.4.5`）・`Alchemist.json`の依存宣言（`min_version: 3.4.5`）と不一致だった。過去のゲームログでは、そもそもBaseLib自体が「設定で無効化」されており、Alchemistも一度も`mods`フォルダに導入されていなかった（＝実機起動確認は未実施だった）。
- 選択肢の検討：(a) 実機のBaseLibをv3.4.5へ更新、(b) GitHub最新のv3.4.7へ更新してから追従、(c) リポジトリ内の不整合のみ修正し実機変更はユーザーに委ねる。
- ユーザーの選択：(a)。理由：3.4.5はビルド時点で動作確認済みの参照バージョンであり、最新3.4.7への追従はAPI差分の確認負荷が増える。
- 実施内容：
  1. 実機`mods/BaseLib`の旧v3.2.0一式をプロジェクト外のスクラッチ領域にバックアップ。
  2. `.tools/BaseLib-3.4.5`の内容（BaseLib.dll/.json/.pck）で実機`mods/BaseLib`を上書き。
  3. `scripts/install.ps1`のバージョンチェックを`v3.2.0`→`v3.4.5`に修正。
  4. `scripts/install.ps1`を実行し、`dist/Alchemist`を実機`mods/Alchemist`へ導入。
  5. `%APPDATA%\SlayTheSpire2\steam\<SteamID>\settings.save`の`mod_settings.mod_list`に`BaseLib`（既存エントリを`is_enabled: true`に変更）と`Alchemist`（新規追加、`is_enabled: true`）を設定。他の導入済みMOD（RouteSuggest, Watcher, UnifiedSavePath）は元々`is_enabled: false`だったため変更していない。編集前の`settings.save`はスクラッチ領域にバックアップ済み。
- 影響：他の導入済みMOD3つはBaseLib依存だが、いずれも現状無効化設定のため直接の動作には影響しない。ただし将来それらを有効化する場合、v3.4.5との互換性は別途確認が必要（未検証）。
- 未決：v3.4.6/v3.4.7への追従、および旧v3.2.0バックアップの最終的な削除タイミング（当面保持）。

## 2026-09-21: v0.2.0 工房の主役カード

- ユーザーの希望「強い切り札を作り、デッキの主役にしたい」に合わせ、通常素材2個のレシピを5種から12種へ拡張。順不同の全10組み合わせを網羅し、鉄2個・薬草2個には基礎カードと主役カードの選択を用意した。
- 7種の追加カードの数値・役割は `src/Alchemist.Core/ForgeCatalog.cs` に集約。大剣、弱体先行攻撃、廃棄連動パワー、毎ターン毒パワー、大量毒、全体攻撃を用意。既存5種も強化した。全て素材2個で、採取量・容量・通常報酬は変更しない。数値は強めの試作値であり、通しプレイで調整済みとはしない。
- 工房に役割・使い方・不足素材・作成可能なものへの絞り込みを追加。完成プレビューは消費なし。
- 新カードは単一のForgedCardモデルと安定したformula IDで保存する。既存カードのモデルID、ランスキーマ1を維持。既存カードの基礎値は更新後の定義に従う。新カードを含むセーブの旧MODへの降格は非対応。未知formulaは黙って初期化せず拒否する。
- 現段階の12種はM1の固定レシピ拡張。ベース3種×10組の基本文法、希少加工、専用工房ノードは未実装のまま。M3完了とは扱わない。
- 更新用scripts/update.ps1はゲーム終了を確認し、旧MODのDLLとマニフェストをworkspaceのartifacts/backupsに保存して更新する。コピー後ハッシュを照合し、失敗時は旧版へ戻す。
