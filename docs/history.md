# 開発履歴（v0.13.0以前）

`README.md`から移した、v0.13.0以前の変更の記録。**現行仕様ではない**。カード報酬の廃止、素材相の自動循環、工房での連続錬成、旧フォーミュラ65種など、ここに書かれた仕組みの多くはその後の版で撤回・削除されている。現行仕様は`AGENTS.md`と`docs/design-axes.md`、各版の判断は`docs/design-decisions.md`を参照すること。

古い仕様をエージェントが現行仕様と誤読した実例があったため、2026-09-26（v0.19.0）にREADMEから分離した。

## v0.13.0：錬成バランスの基盤修正

- 作成可能なレシピを83枚から65枚へ整理。2素材は順不同の10組み合わせにつき1枚、3素材20枚、4素材35枚とした。
- 旧2素材レシピ18枚の定義IDは既存セーブの読込用に残すが、新しく作ることはできない。
- 2素材帯から恒久筋力・恒久敏捷・多段攻撃を外した。多段攻撃は3素材と4素材に各1枚だけ配置した。
- 3素材の筋力・敏捷は最大1、4素材は最大2へ抑えた。3枚のレシピに、現在ターンを変えず素材相だけを進める効果を追加した。
- 既存カード強化は工房1か所につき1枚。カード錬成は素材が続く限り複数回行える。
- 商人の通常画面に「錬金素材を見る」ボタンを追加。訪問ごとに決定する通常素材3枠を、各1回・35Gで購入できる。再表示やロードで在庫は変わらない。
- 素材取得2倍、容量20、通常カード報酬なしという経済の基本条件は維持している。

## v0.9.1：カードと素材の双方向錬成UI

工房のカード錬成を、次の2方向から利用できるようにした。

- **カードから探す**：従来どおり完成カードの一覧から選び、必要素材を確認する。
- **素材から作る**：Minecraftの作業台のように通常素材を2枠へ置き、その組み合わせから作れるカードだけを表示する。同種素材も2個置ける。素材の順番は問わない。

素材スロットへの配置はプレビューであり、この時点では消費しない。表示されたカードを選んで「このカードを作る」を確定した時だけ素材を2個消費する。

## v0.9.0：希少素材・恒久加工・レシピ表示修正

希少素材3種を追加した。工房の「希少加工」で錬成カード1枚へ1つだけ恒久効果を刻む。素材は加工時に消費され、取り外し・回収・上書きはできない。

| 希少素材 | 恒久効果 |
|---|---|
| 水銀 | 保留を得る |
| 星砂 | リプレイ1回を得て、カード効果が合計2回発動する |
| 虚無結晶 | コストが1減り、廃棄を得る |

- ボスの2枠中1枠は3候補すべて希少素材。初期3種をすべて提示する。
- エリート枠とボスの非保証枠は、25%の確率で3候補中1個が希少素材になる。
- 通常素材と希少素材は容量10を共有し、満杯なら同じ交換・辞退手順を使う。
- schema 1/2の既存ランは、通常素材と未解決報酬を保持したままschema 3へ移行する。
- レシピ一覧を初めて開いた時、一部カードに `If you can read this, there is a bug.` が残る問題を修正した。プールされたカード表示ノードを、内部ラベルの準備後に再描画する。

## v0.8.0：炉の起動による素材採取

通常素材は、敵を倒した時ではなく、**《炉の起動》で手札を廃棄した直後**に現在相の素材を1個得る。炉の起動は戦闘全体で2回までなので、敵が1体でも複数でも、1戦で狙える通常素材は同じ最大2個になる。カードを選ばず取り消した場合や、廃棄に失敗した場合は素材を得ない。

## v0.7.0：エリート・ボスの素材報酬

《炉の起動》による通常素材の採取とは別に、報酬画面へ素材を選ぶ枠を追加した。

| 部屋 | 枠 | 内容 |
|---|---|---|
| エリート | 1枠 | 3候補から素材1個 |
| ボス | 2枠 | 各3候補から素材1個（計2個） |

- ゴールド・カード・レリック・ポーションの既存報酬はそのまま残る。素材枠が追加されるだけで、置き換えはしない。
- 候補はランのシードと報酬枠IDだけから決まる。画面を開き直しても、セーブして再開しても、同じ3候補が出る。ゲーム側の乱数列は消費しない。
- 素材ボックスが満杯のときは、通常素材と共通の受け取り手順（交換か辞退）へ合流する。黙って捨てることはない。
- 枠の辞退は可能。辞退した枠は戻らない。
- 未解決の枠が残っているあいだは次の部屋へ進めず、工房での錬成・強化もできない。
- v0.7.0時点では希少素材が未実装だった。v0.9.0でボスの片方を希少確定枠へ変更した。

## v0.4.0：マップ工房・既存カード強化・連続する素材相

この節はv0.4.0当時の記録。v0.13.0以降、通常素材2個で作れるカードは10種で、各組み合わせにつき1枚となっている。

| 目指すデッキ | 主役のレシピ・未強化時の効果 |
|---|---|
| 大きな一撃 | 鉄＋鉄《錬鉄の大剣》：2コスト、28ダメージ＋8ブロック、保留 |
| 毒で押し切る | 薬草＋薬草《猛毒培養槽》：1コストのパワー、毎ターン敵全体に毒4 |
| 廃棄を戦力に | 鉄＋エーテル《循環錬成炉》：2コストのパワー、廃棄のたび5ブロック＋1ドロー |
| 集団戦の切り札 | 火薬＋エーテル《エーテル爆縮》：1コスト、全体24ダメージ＋2ドロー、廃棄 |

このほか徹甲榴弾・毒霧爆弾・濃縮毒液を追加し、既存5種も強化。数値は強めの試作値で、通しプレイによるバランス検証はこれから。既存カードのIDとラン保存形式は維持するが、新カードを含むセーブを旧MODへ戻すことは非対応。

v0.3.0では《合金乱舞》《回転式錬金砲》《毒針斉射》《連鎖爆轟》《星屑弾幕》などの多段攻撃、《金剛の霊薬》《火薬律動》などの筋力、《補強行列》《軽業の蒸留液》などの敏捷、《戦支度の霊薬》《霊質変成》など攻守両方を伸ばすパワーを追加した。多段攻撃は筋力が各ヒットへ適用される。

工房は左側に素材ボックス、右側に完成後のカードそのものを一覧表示する。カードを選ぶと一枚を大きく表示し、必要素材、役割、使い方、現在効果、強化後効果を確認してから「このカードを作る」か「一覧へ戻る」かを選べる。作成可能な候補だけへの絞り込みにも対応する。

工房はマップ生成時に既存の「？」を置き換えて配置される。通常の休憩所と同程度の個数で、序盤から中盤にも到達できるようAct内へ分散し、金色の商店型アイコンと「工房」ラベルで事前表示する。通常の休憩所、商人、戦闘、エリートは置き換えない。

工房ではカード錬成と既存カード強化を切り替えられる。強化コストは試作として、アタック＝鉄＋火薬、スキル＝薬草＋エーテル、パワー＝火薬＋エーテル。現在と強化後のカードを並べて確認してから実行する。

素材相は戦闘ごとに鉄へ戻らない。戦闘終了時の次の相を保存し、次の戦闘はそこから開始する。たとえば鉄相で終えた次の戦闘は薬草相から始まる。
