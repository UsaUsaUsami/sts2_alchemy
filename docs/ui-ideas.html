錬金術師MOD UI改善案（モック）

実装は WorkshopUi.cs（944行、ボタン中心の1画面）・PhaseDial.cs・MaterialStrip.cs が対象。以下はゲーム内の見た目の方向性を示す静的モックで、数値は仮です。

1. 工房の4設備を「工程の道しるべ」にする 優先高

今は「錬成\n使用可能」という文字ボタン。アイコン＋状態の色＋「今ここ」の強調にして、1訪問に各1回という制約が一目で伝わるようにする。使用済みは暗く、素材不足は不足分を明示。

⚗ 錬成使用可能
🔧 改造使用可能
🧪 調薬使用済み ✓
✦ 付与希少素材が必要（0/1）

退出ボタンは未使用の設備が残っているとき「まだ○個の設備が未使用です」と確認を出すと、取りこぼしを防げる。

2. 錬成：炉の陣と“作る前に見える”プレビュー 優先高

素材をクリックして陣のスロットに入れると、右のカードがリアルタイムに更新される。素材チップは所持数・配置数を丸数字で、足りない素材は薄く。「あと1個で別のレシピ」を提示して発見を促す（プレビューは読み取り専用の原則を守る）。

4. 戦闘中：炉と相ダイヤルを1か所にまとめる 優先高

現在相、「炉の起動の残り回数」、「今炉を使うと得られる素材」を相ダイヤルの近くに寄せる。0個では使えない無相のときは炉の表示を灰色にして理由を出す。

炉 残り1回　→ 廃棄で 火薬 ＋1

相ダイヤルへのホバーで上のツールチップを出せば、バニラにないキーワードの説明が常に参照できる。

6. 報酬選択（エリート・ボス）

素材カードに「今の素材と組み合わせて作れるレシピ数」を小さく添える。希少は金の枠線＋「希少」バッジ。辞退ボタンは目立たない位置に置き、誤クリックを避ける。

7. 全体に効く小改善

  • 日本語の長文はツールチップへ逃がし、ボタン文言は1行まで（今は改行入りボタンが多い）。
  • 素材・相の色を地=琥珀 / 水=青 / 火=朱 / 風=翠に固定し、色覚対応のため形（◆▲●★など）も併用する。
  • 確定操作は「確認ダイアログ」でなく、確定ボタン長押し or 結果カードの2段階クリックで軽くする。
  • 操作の取消（素材を戻す）を各画面の同じ位置・同じ見た目に統一。
  • コントローラー入力・キーボードのフォーカス順を工房画面で確認（AGENTS.mdの実ゲーム検証項目）。
